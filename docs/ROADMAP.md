# 路线图

## 0.1 — Windows 素材准备 MVP（已实现）

目录扫描、MD/TXT、多格式原图、原图全览、非破坏性派生、拖出、剪贴板与 DOCX、诊断日志。

## 0.2 — 四平台日常工作流（本轮）

- [x] 单篇/文章库/自动目录模式、多来源与历史恢复、来源变更提示
- [x] 编辑缓冲、串行落盘、保存状态/重试、切换/关闭保护
- [x] 公众号、小红书、X、知乎独立稿与统一 profile
- [x] 图片选择、顺序与交付版本持久化
- [x] X 标准单条加权计数/四图，未知规则与自定义预算区分
- [x] 一键完整交付包与追溯清单
- [x] 本地账号标记、人工发布状态、链接/备注、状态筛选
- [x] 损坏记录保护、跨目录链接防护、回归测试

验收与包信息见 [优化文档](OPTIMIZATION-PLAN.md)。

## P2 — 高效运营与真实平台验证（未实现）

- 真正多账号实体、账号级模板/预算继承、内容类型与授权范围。
- X 串文/Premium 长文、知乎回答模板、公众号封面和正文图角色、插图锚点。
- 批量适配、任务进度/取消、自定义画布、派生文件历史清理。
- 增量扫描与缩略图缓存，大库性能基准。
- 平台后台实测矩阵：富文本粘贴、上传顺序、排版/拒绝反馈、规则复核与版本管理。

## P3 — 协作与反馈（未实现）

发布日历、审稿/版本差异、官方授权 API 草稿同步、人工/授权反馈指标、可选 AI 辅助适配。平台 API 必须与本地准备流程解耦；不以 Cookie 接管或无人值守代发作为默认方案。
