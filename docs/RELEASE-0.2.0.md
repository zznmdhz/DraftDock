# DraftDock 0.2.0 — 四平台本地交付工作流

本轮从产品经理、真实用户和官方平台规则三个视角审计，并按修改文档实现Windows工作流优化。

## 改进

- 单篇图包/多篇文章库/自动模式，MD/TXT多来源、外部变更提醒和可恢复历史。
- 主稿、公众号、小红书、X、知乎独立工作稿；统一平台入口、格式、图片预设和规则来源。
- 持久化每个平台的选图、发布顺序与派生版本；失效素材可移除，派生失效提示。
- X 标准单条加权字符/四图检查，其他未核实上限不填假值；账号自定义预算独立提醒。
- 完整发布包：标题、纯文本、Markdown、HTML、有序PNG、manifest和人工检查单。
- 目标账号标记、人工发布状态、链接、备注与状态筛选。
- 编辑缓冲/串行保存/重试，切换、正常关闭和受控重载前保存保护。
- 损坏状态不覆盖、路径链接边界保护、恢复入口、诊断日志。

## 验证

类型检查、45项测试、Windows打包均通过。真实图包副本验证2份正文/10张图，打包程序完整回归覆盖立即切换/重载/关闭、图片顺序与版本、四平台交付、来源历史、原素材hash不变以及1180×720布局。

安装版与便携版均为Windows x64。下载后运行安装版升级，或便携版直接运行；原始文章与图片不覆盖。

本轮包未使用商业代码签名证书，Windows可能显示SmartScreen提示；请核对发布来源与SHA-256。

## 边界

这是发布准备台，不自动登录/发布。账号字段是本地标记，不代表账号认证。X串文/长文、知乎回答、精确插图、多账号模板、批量队列、日历/效果分析和官方授权API仍待后续。平台后台上传、富文本粘贴和账号差异需要人工确认。图片尺寸是工作预设，不伪装成官方强制标准。

完整修改文档、产品/用户审计和平台研究见仓库 `docs/OPTIMIZATION-PLAN.md` 与 `docs/audit/`。
